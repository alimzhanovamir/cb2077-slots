# Known limitations (MVP)

These limitations are accepted on purpose for the first version.

| Area           | Limitation                                                                                                                                                      | Why it is acceptable / when to lift it                              |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| Storage        | Node.js server keeps sessions in memory; any restart (including `tsx watch` reloads in development) resets balances                                             | Emulator; the client shows "Session reset" and starts a new session |
| Scaling        | A single server instance; no horizontal scaling                                                                                                                 | Not needed for an emulator                                          |
| Security       | No authentication: the `sessionId` is the only key to a session; the debug drawer is available to everyone; no rate limiting, no Origin check, no TLS (`ws://`) | Play money; a deployed server needs at least `wss://`               |
| Versioning     | No protocol version: client and server must come from the same commit                                                                                           | Monorepo, deployed together (ADR 002)                               |
| Math           | RTP is neither calculated nor verified; reel strips and paytable are tuned by hand                                                                              | Not a goal of the MVP                                               |
| Features       | No Wild/Scatter, bonuses, Turbo, paytable screen, round history UI, sound or final art                                                                          | See [roadmap](roadmap.md)                                           |
| Tabs           | Only one tab can play at a time — by design                                                                                                                     | ADR 008                                                             |
| Background tab | Spins pause while the tab is hidden                                                                                                                             | Browsers stop animation frames in background tabs                   |
| WebGL          | Loss of the WebGL context (e.g. a phone waking up after a long sleep) is not handled; a reload is needed                                                        | After the MVP                                                       |
| Accessibility  | The canvas UI is invisible to screen readers; keyboard support is limited to Space                                                                              | After the MVP                                                       |
| Localisation   | English UI only                                                                                                                                                 | UI texts are already in `texts.ts` files (platform, game)           |
| Orientation    | Portrait screens show a scaled-down landscape layout                                                                                                            | Dedicated portrait layout after the MVP                             |
| Testing        | Mobile E2E is emulation; real devices are checked manually                                                                                                      | NFR-07                                                              |
| Demo mode      | Tab takeover is not emulated: each tab runs its own emulator over a shared `localStorage`, last write wins                                                      | Demo mode for GitHub Pages                                          |
| Demo mode      | The "server" runs in the page; balance and outcomes can be changed from the browser console                                                                     | Play money, demo                                                    |
| IP             | Name, the "eddies" currency (€$) and the theme reference Cyberpunk 2077 (CD Projekt)                                                                            | Non-commercial project; revisit before any publication              |
